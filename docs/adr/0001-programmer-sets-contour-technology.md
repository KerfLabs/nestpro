# The programmer sets each contour's technology, during import and after

Drawings reach the shop with no reliable cut or mark information: most put everything on one
layer, and etchings are often added by the programmer later. So whether a contour is cut, marked
or left out is decided by the programmer contour by contour, and drawing layers are only a
shortcut for the drawings that do use them. Unlike Lantek Expert, which imports everything as cut
and has the programmer fix contours afterwards in the part's drawing screen, the rebuild lets the
programmer set this while importing (on a preview of the drawing) and also later on the part, with
the same tools. A part saved this way keeps each contour's choice, so going back to a purely
layer-based import would mean redoing saved products.
